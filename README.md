# Escritório

Animação em pixel art de um escritório, com relógio no fuso America/Sao_Paulo.
Página estática única (`index.html`), sem dependências nem build.

## Teste
Adicione na URL: `?h=07:59:50&speed=1` (ou `speed=60` para acelerar).

## Publicar no GitHub Pages
1. Suba os arquivos para um repositório.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
